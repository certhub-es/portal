# CertHub Portal (`certhub.es`)

Repositorio principal de la plataforma **CertHub**, que sirve la página de inicio y el catálogo de certificaciones bajo `https://certhub.es/`.

## Tecnologías
- **Vite** + **React 19**
- **Cloudscape Design System** (`@cloudscape-design/components`)

## Comandos

### Instalar dependencias:
```bash
npm install
```

### Ejecutar localmente:
```bash
npm run dev
```

### Compilar y Desplegar a AWS S3 / CloudFront:
```bash
npm run deploy
```
